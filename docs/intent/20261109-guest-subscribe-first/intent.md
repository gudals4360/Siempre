## 문제와 기대 효과

- `npm run dev` 후 첫 화면이 로그인이라, MVP 시연에서 서비스의 핵심(쓸 AI를 골라 담는 구독 화면)을 바로 보여 줄 수 없었다.
- 요청자 요청: "MVP할 때 바로 구독창에서부터 보여 주고 싶다".

## 결정

- 구독 화면은 로그인 없이 둘러볼 수 있게 하고, **실제로 시작할 때**(이 구성으로 시작하기 / 무료로 시작하기 / 대화·크레딧 이동 / 시연 버튼 E1·E2)만 로그인을 받는다.
- 로그인 화면으로 갔다 와도 고른 구성이 사라지지 않게 담은 AI 단계·결제 주기를 sessionStorage에 잠깐 저장하고, 돌아오면 되살린 뒤 누르려던 동작을 이어서 한다.
- 권희수 님 HTML은 고치지 않는다 (연결 스크립트 `frontend/src/bridge/prototypeAuth.ts`만 변경). 대신 그 화면의 전역 상태 `S`, 함수 `renderSub()`, 버튼 id(`start`, `startFree`), `data-go` 이름에 기대므로 바뀌면 알려 달라고 PR에 적는다.

## 기획과의 관계 (⚠️ 팀 확인)

- `docs/PRD.md`는 `de12e6f`에서 PRD03 기준으로 정리됐고, 회원가입·로그인은 **7-0**(A-1~A-4)에 있어요.
- A-3 "로그인하지 않은 사용자가 구독·대화·크레딧 화면에 들어오면 로그인 화면으로 보낸다" → 이번 변경으로 **구독 화면 둘러보기는 허용**, 대화·크레딧·결제(시작하기)는 그대로 로그인 필요. A-3 문구 조정이 필요하다.
